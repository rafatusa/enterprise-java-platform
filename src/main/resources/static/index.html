API

MethodPathDescription
POST/api/v1/auth/loginExchange credentials for a JWT
GET/api/v1/tasksList tasks, optionally filtered by status
GET/api/v1/tasks/urgentTasks at priority 1 or 2
POST/api/v1/tasksCreate a task
GET/api/v1/tasks/{id}Fetch one task
PUT/api/v1/tasks/{id}Replace editable fields
PATCH/api/v1/tasks/{id}/statusTransition status
DELETE/api/v1/tasks/{id}Delete a task

Quick start

Obtain a token, then call a protected endpoint:

curl -X POST /api/v1/auth/login -H 'Content-Type: application/json' -d '{"username":"operator","password":"..."}'

curl /api/v1/tasks -H 'Authorization: Bearer <token>'
